# ARE-Sandbox：マクロ経済複雑系シミュレーター公式解説書

## 🌌 1. ARE-Sandbox とは

ネット上やSNS、議論の場における経済政策の議論は、しばしば感情的な罵倒や前提の異なる「空中戦」に陥りがちです。増税か減税か、量的緩和か引き締めかといった対立において、客観的なファクトと理論的因果が共有されないことがその原因です。

**ARE-Sandbox** は、こうした不毛な空中戦を調停し、**「どの政策ツマミを動かせば、どこに、どれだけの時間軸で影響を与えるか」** を、全員の目で動的に共有・検証するために設計された、完全決定論的なマクロ経済動学シミュレーター（経済の実験室）です。

本 Sandbox では、日本の実際の経済データ（令和8年度予算ベースのストック・フロー）に数理モデルを較正し、財政・金融・為替・債務の複雑な相互作用をリアルタイムでシミュレーションすることができます。

## 🕹️ 2. シミュレーターの操作方法（議論の作法）

本シミュレーターは、以下の3つのステップを通じて、経済政策の効果を客観的に検証し、他者と議論を深めることができます。

### ① 初期シナリオ設定 (t=0 Inputs)
シミュレーション開始時点（t=0）における経済の初期状態を、現在の実測ファクトデータに基づいて自由に変更できます。
- **初期名目GDP、初期政府債務残高、初期インフレ率、初期政策金利、初期為替レート、初期日銀国債保有量** をフォームに入力することで、民間国債残高や日銀当座預金、初期長期金利などの連動変数が整合的に自動算出（ハイドレーション）されます。

### ② 政策介入レバー（スライダー操作）
操作パネルのスライダーを動かした瞬間に、数理モデルが瞬時に差分方程式を再計算し、**今後30ステップ（四半期換算、約30年間分）の未来の軌道** がCanvasグラフ上にカラー折れ線として秒速で描画されます。政府支出（G）や税率（τ）、日銀の国債買い入れオペ額（Op）を変更した際、インフレや為替、国債残高がどのように動くかをインタラクティブに観察できます。

### ③ 前提の完全共有機能（URL同期）
あなたが調整した「絶妙なバランスの政策・初期設定パラメータ」は、画面下部の **【リンクをコピー】** ボタンを押すだけで、クエリパラメータを含むURL（例: `?G=100&tau=0.20&Y0=691.9...`）としてクリップボードにコピーされます。
このURLを掲示板やチャットに貼り付けるだけで、相手の画面でも**全く同一の前提・全く同一の未来の軌道**が瞬時に再現（状態の同期伝播）されます。これにより、「同じ前提に立った建設的な検証」が可能になります。

## 📊 3. 主要指標・用語および単位の説明

シミュレーター内で観測できる指標とその役割は以下の通りです。

| 指標名 | 変数記号 | グラフ色 | 単位 | 経済学的説明 |
| :--- | :---: | :---: | :---: | :--- |
| **名目GDP** | `Y` | 🟢 エメラルド | 兆円 | 経済全体の総需要。実質GDPにインフレ率を乗じて算出されます。 |
| **政府債務残高** | `B` | 🔴 バーガンディ | 兆円 | 累積する普通国債発行残高。金利上昇に伴う利払い費がここに蓄積されます。 |
| **インフレ率** | `pi` | 🟡 アンバー | % (年率) | 需給ギャップ（GDPと潜在GDPの差）および為替変動コストから算出される物価上昇率。 |

## 🧠 4. 数理コアに実装された経済理論的背景

本ツールは単なるランダムな数値生成ではなく、強固なアカデミックの経済理論の方程式をベースに構築されています。これにより、シミュレーション結果に対する高い客観性と信認性を担保しています。

### 1. ストック・フロー一貫性（SFCモデル）の担保
マクロ経済学における「誰かの支出は誰かの収入である」という大原則を厳密に実装しています。政府の財政赤字フロー（歳出 － 税収）は、1円の狂いもなく国債残高ストック（B）の加算および民間部門の純金融資産増加（B_private）へ物理変換されます。毎ステップの監査ログにおいて、この会計的整合性は等式として完全に成立（Balanced: true）し続けています。

### 2. 特定期間選好・市場分断仮説に基づくターム・プレミアム（τ）
日銀が長期国債買い入れオペ額（Op）を減額（量的引き締め: QT）すると、市場に流通する国債シェア（B_private / B）が増加します。これにより、民間投資家が国債を引き受けるための「上乗せ金利（タームプレミアム）」が拡大し、市場長期金利（R）を押し上げる因果関係を実装しています。
$$R_t = \max\left(r_t, r_t + \tau_t +リスクプレミアム\right)$$

### 3. 国債借り換え遷移モデル（ヤコビアン平滑化）
「金利が上がると政府の利払い費が即座に爆発する」という単純モデルの不整合を排除し、日本の普通国債の平均残存期間（約7〜9年）を反映した「借り換えダイナミクス」を実装しています。
金利が上昇した際、全債務が一斉に新金利に切り替わるのではなく、その期（四半期）に満期を迎えて借り換えられる割合（λ = 0.03、年間約12%）のみが順次新金利に置き換わります。これにより、利払い費の現実的かつ平滑化された累積動学を再現しています。
$$\text{interest\_payment}_t = B_t \times \left( (1 - \lambda) \times R_{\text{init}} + \lambda \times R_t \right)$$

### 4. 購買力平価（PPP）と国際金利平価（UIP）の二大索調停
オープンマクロ経済における為替決定プロセスにおいて、長期的トレンドを決定する「自国と海外のインフレ差（購買力平価）」と、短期的・投機的な資金移動を決定する「自国と海外の政策金利差（金利平価）」のシーソーを数式化しています。インフレ低下（円高圧力）と金利低下（円安圧力）が動的に均衡する中で、為替レートが推移します。

## 🚫 5. 本シミュレーターの限界と限界の超え方

本ツールは議論の前提を可視化する強力な武器ですが、万能の予言書ではありません。以下のシステム限界を理解した上で、より深い議論の材料として活用してください。

- **決定論的モデルの制約（確率的ショックの排除）**
  - 本モデルは純粋な経済動学の因果ループを理解しやすくするため、予期せぬ外部ショック（震災、パンデミック、国際紛争等）による乱数を排除した決定論的差分方程式として記述されています。
- **期待形成の不変性（センチメント定数の近似）**
  - 民間のインフレ予期や市場のセンチメントの不連続な変化は、方程式内の一定の「感応度定数」として近似されています。実際の市場で起きるような「期待の自己実現的なパニック暴走」は表現しきれない限界があります。
- **「ARE-Sandbox」多次元ポータルへの布石**
  - 本「日本経済モデル」の限界を補完するため、今後は **「ARE-Sandbox」** 配下に「雇用・労働市場モジュール」「エネルギー・資源需給モジュール」「地政学サプライチェーンモジュール」などを独立した別個の部屋（Sandbox）として順次追加していく計画です。これらを組み合わせて多次元的に分析することで、限界を超えた高度なマクロ経済・社会シミュレーションを展開するビジョンを持っています。
