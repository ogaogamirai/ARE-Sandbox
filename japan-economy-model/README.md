# 🌌 ARE-Sandbox マクロ経済シミュレーター公式解説書

本プラットフォームは、ネット上のコミュニケーションにおいて、一方的な感情論の言い合いを調停し、客観的な「前提（事実・数理的理論背景）」を共有した有意義な政策対話を行うために創出されたマクロ経済動学実験室（サンドボックス）です。

## 🕹️ 1. シミュレーターの使い方（議論の作法）
1. **初期シナリオ設定 (t=0)**: 画面上部の入力フォームから、開始時点の「名目GDP」「政府債務残高」「初期為替」「初期インフレ率」等の実態データを自由に変更可能です（前提ファクトの自由化）。
2. **政策介入（ツマミの操作）**: 「政府支出」「政策金利」「日銀国債買い入れ額」などの政策レバー（スライダー）を動かした瞬間、120期（四半期換算：30年間分）の未来 of 軌道がCanvas上にカラー線で即座に再計算・描画されます。
3. **前提の完全同期共有 (Share機能)**: 画面内の「共有リンクをコピー」ボタンを押すと、現在のすべてのスライダーと初期入力値が埋め込まれた固有のURLパラメータが生成されます。これを掲示板やチャットに貼り付けるだけで、相手のブラウザ上でも全く同じ未来の軌道を再現でき、建設的なディベートを可能にします。

## 📊 2. 主要指標および単位の定義
- **名目GDP (Y)** `[単位: 兆円]`: 総需要の合計。実質需要ギャップが成長率にフィードバックされます。
- **民間可処分所得 (Yd)** `[単位: 兆円]`: 名目GDPから税金を引き、政府支出の変化分を加味した民間セクターのネット所得。政府支出の削減（緊縮）がダイレクトに毀損される構造を形成します。
- **民間消費 (C)** と **民間投資 (I)** `[単位: 兆円]`: 消費は可処分所得 `Yd` の規模（消費性向 約0.6256）に依存し、投資は金利 `R` の低下による刺激（通常時）と金利上昇ペナルティの双方を受けて決定されます。
- **政府債務残高 (B)** `[単位: 兆円]`: 累積する国債残高。市場金利に連動した利払い費が蓄積します。
- **インフレ率 (π)** `[単位: % (年率同期済)]`: 需給ギャップ（潜在GDPとの差）から算出される物価上昇率。
- **政策金利 (r)** `[単位: %]`: 中央銀行が誘導する短期金利。
- **日銀国債買い入れ額 (Op)** `[単位: 兆円/月]`: 月間の長期国債オペフロー。**※本シミュレーター内部では「1期（1ステップ）＝ 3ヶ月（四半期）」として時間軸が定義されており、月間設定値を3倍して期ごとのフローとしてストックに反映しています。**
- **日銀国債保有残高 (BOJ)** `[単位: 兆円]`: 日銀のバランスシートの規模（ストック）。
- **為替レート (E)** `[単位: 円/ドル]`: 通貨の相対価値。内外金利差とインフレ差から動的に算出されます。

## 🧠 3. 実装された経済理論的背景
本ツールは、ただのグラフィックではなく、以下の強固なマクロ経済因果律を媒介として連携しています。
- **ストック・フロー一貫性（SFC理論）と緊縮のパラドックス**: 「誰かの支出は誰かの収入」であり、政府支出 `G` の削減が民間可処分所得 `Yd` と消費 `C` を直接的に引き下げます。これが総需要ギャップを通じて実質成長率を押し下げ、結果として「緊縮を行ったのに、分母のGDP縮小スピードが分子の国債減少を上回り、債務対GDP比率がむしろ悪化する」というデフレ・スパイラル（緊縮のパラドックス）を完璧に再現します。
- **流動性の罠（Liquidity Trap）の相転移**: インフレ率が 0.5% 未満となる深刻なデフレ圏においては、いくら金利が低下しても民間投資が刺激されない「流動性の罠」を表現するため、金利低下による投資刺激効果が通常時の 15% に動的に減退する閾値分岐をマウントしています。
- **市場流動性枯渇と不規則な金利スパイク**: 日銀の急速な国債買い入れ減額（月2兆円以下のオペ相当の急激なQT）や、政府の急激な国債発行停止（超緊縮）が市場の流動性を急激に枯渇させた際、長期金利 `R` に不規則な暴騰プレミアム（4% 〜 6% の変動スパイク）が加算され、金利コントロールが不可能になる市場取引リスクをシミュレートします。
- **特定期間選好・市場分断仮説**: 日銀が国債買い入れ額を減額（QT）すると、市場流通国債 of 需給が緩み、上乗せ金利である「ターム・プレミアム」が拡大して市場長期金利が上昇するメカニズム。
- **国債借り換え遷移（ヤコビアン平滑化）**: 日本の国債平均残存期間（約7〜9年）に適合し、金利が上昇してもその期に満期を迎えて借り換える分（全体の約3%）にのみ新金利が順次適用されるリアルな財政利払い動学。
- **金利平価（UIP）と購買力平価（PPP）の調停**: 短期的な金利差（利上げによる円高圧力）と、長期的な物価上昇差（円安圧力）がシーソーのように為替を決定するオープン・マクロ動学。

## 🚫 4. 本シミュレーターの限界
- **確率的ショックの排除**: 確率的なランダムショック（予測不能な震災や国際紛争などの外部スパイク）は数式から排除されています。
- **期待形成の不変性**: 心理的な予期（センチメントの暴走やパニック）は、一定の感応度定数として近似されており、非連続な市場の決壊は表現しきれない制約があります。
- 今後は、雇用、エネルギー、地政学リスク等の多次元変数を「ARE Sandbox」配下の個別モジュールとして順次シリーズ解放し、この限界を多面的に補完していきます。

> ⚠️ **マクロ感応度パラメータに関する注意点**
> 本シミュレーターに実装されている各種感応度定数（金利差による為替変化率、国債流通比率によるターム・プレミアム上昇幅、需給ギャップによる物価伝播率など）は、マクロ動学の「方向性」を視覚化するために調整された近似値であり、特定の学術論文や中央銀行の静的推計値を永久に固定したものではありません。
> ネット上の対話や政策ディベートで本ツールを活用する際は、個々の数値の絶対的な的中精度ではなく、**「あるレバーを動かしたとき、どの変数に、どれだけの時間的猶予で、どのようなベクトル（好循環/悪循環）の影響が波及するか」という構造的因果関係（前提）の共有**に主眼を置いて議論を展開してください。
