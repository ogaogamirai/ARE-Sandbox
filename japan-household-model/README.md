# JAPAN-A_Living 国民生活・雇用影響シミュレーター (japan-household-model)

本シミュレーターは、マクロ経済の変動（物価、政策金利、長期金利、成長率）が「購買力」「雇用・格差」「社会保障・生活負担」「産業変革」に与える動学的な波及効果を視覚化し、議論の前提となる構造論理的な因果関係を共有するための動学シミュレーションツールです。

兄弟プロジェクトである「JAPAN-A_Core マクロ経済シミュレーター」と並行・ドッキング可能な「家計・労働部門」のモデルとして設計されています。

---

## 🧭 1. シミュレーションの基本変数と指標

### 1.1 主要出力指標 (Output Indicators)
* **実質賃金 ($W_{real}$)** `[単位: 指数 (初期値 100)]`: 名目賃金をマクロインフレデフレーターで調整した購買力の指標。「名目賃金の伸びが物価上昇を上回り、実質賃金がプラス転換するか」を追跡します。
* **家計可処分所得 ($YD$)** `[単位: 兆円]`: 名目賃金および預金金利受取から、税、社会保険料、住宅ローン利払い金利負担を差し引き、給付付き税額控除を加算した、家計が実際に使える資金フロー。
* **住宅ローン支払負担 ($Cost_{loan}$)** `[単位: 兆円/期]`: 金利上昇に伴う住宅ローン返済額の増加。変動金利比率に応じて政策金利 $r$ および長期金利 $R$ の上昇が牙を剥きます。
* **大中小企業賃金格差 (Wage Inequality)** `[単位: 乖離率 %]`: 大企業賃金と中小企業賃金の乖離。中小企業の価格転嫁率（パススルー）が低いほど格差が拡大する構造をモデル化しています。
* **労働供給量 ($L_{supply}$)** `[単位: 労働供給指数]`: 最低賃金の引き上げに伴い、「年収の壁（配偶者控除・社会保険の壁）」を意識した非正規労働者が就業時間を自発的に削減する就業調整効果（労働供給ペナルティ）。

### 1.2 政策・シナリオスライダー (Inputs / Policy Levers)
* **中小企業価格転嫁率 ($\alpha_{pass}$)** `[初期値: 0.50, 範囲: 0.0 - 1.0]`: 中小企業が原材料費や人件費のコスト高を下請け価格や販売価格に転嫁し、賃上げ原資を確保できる割合。
* **最低賃金引上げ幅 ($\Delta MW$)** `[初期値: 3.0%, 範囲: 0.0% - 10.0%]`: 年率換算の最低賃金引き上げ率。非正規の賃金を底上げする一方、就業調整（壁）のトリガーになります。
* **社会保険料率調整幅 ($\Delta \tau_{social}$)** `[初期値: 0.0%, 範囲: -5.0% - +5.0%]`: 後期高齢者医療や介護保険の財源を支えるための現役世代の負担調整。
* **給付付き税額控除規模 ($ETC$)** `[初期値: 0兆円, 範囲: 0兆円 - 10兆円]`: 低所得世帯への所得補填規模。
* **リスキリング・労働流動化支援度 ($G_{reskill}$)** `[初期値: 0兆円, 範囲: 0兆円 - 5兆円]`: 政府による労働移動支援の規模。短期的には摩擦コストが発生しますが、中長期的には潜在生産性を押し上げます。
* **変動金利ローンシェア ($Loan_{var}$)** `[初期値: 0.70, 範囲: 0.0 - 1.0]`: 全住宅ローンに占める変動金利型の割合。

## ⌛ 2. 時間軸の定義
本シミュレーター内部では、**「1期（1ステップ）＝ 3ヶ月（四半期）」** として時間軸が定義されており、すべてのフロー変数（賃金、所得、利払いなど）は期ごとのフローとして算出・蓄積されます。デフォルトのシミュレーション期間は **30期（7.5年）** です。

## ⚠️ マクロ感応度パラメータに関する注意点（学術・構造防壁）
本シミュレーターに実装されている各種感応度定数（金利上昇による住宅ローン変動率、最低賃金上昇に伴う就業調整弾力性、価格転嫁から賃金への伝播率など）は、政策および国民生活への波及経路の「方向性」を視覚化するために調整された近似値であり、特定の学術論文や政府の静的推計値を永久に固定したものではありません。

ネット上の対話や政策ディベートで本ツールを活用する際は、個々の数値の絶対的な的中精度ではなく、**「あるレバーを動かしたとき、どの変数に、どれだけの時間的猶予で、どのようなベクトル（好循環/悪循環）の影響が波及するか」という構造的因果関係（前提）の共有**に主眼を置いて議論を展開してください。

## 🧭 3. 基本シナリオの設定と影響

UI上の「基本シナリオ」から選択できる各シナリオの具体的な設定と、それがシミュレーション全体へ与える影響は以下の通りです。

### 3.1 標準シナリオ (`baseline`)
* **為替レート初期値**: 140 円/ドル
* **シミュレーションへの影響**: 極端な円安ストレスや外部ショックがない、安定的で緩やかな景気循環状態です。輸入物価高による実感インフレの上振れが発生しないため、政策スライダーを標準的な位置（転嫁率50%、最賃3%など）に置いた場合、マクロインフレ・金利ともに安定的に推移し、家計の実質可処分所得も安定して成長します。

### 3.2 高インフレ円安シナリオ (`high-inflation`)
* **為替レート初期値**: 170 円/ドル （大幅な円安ショック）
* **シミュレーションへの影響**: 悪い円安による輸入物価（食料やエネルギー）の高騰を表現します。為替ショック（`FX_shock = 13.3%`）が直接的に「生活実感インフレ率（`pi_living`）」を押し上げ、家計の実質購買力を圧迫します。食料自給率が低いほど、この悪影響は増大します。

### 3.3 日銀利上げ・金利上昇シナリオ (`interest-rise`)
* **為替レート初期値**: 135 円/ドル （日米金利差縮小による円高）
* **シミュレーションへの影響**: 円高方向へ振れるため輸入インフレは収まりますが、インフレ目標（2%）乖離や需給ギャップにともない日銀の政策金利（および長期金利）が強く引き上げられます。金利上昇にともない、変動金利ローンを組んでいる家計の「ローン支払負担（`Cost_loan`）」が急増して実質可処分所得を圧迫するほか、企業の金利負担増から限界費用が上がり、コストプッシュインフレが発生しやすくなります。

### 3.4 スタグフレーション（ゼロ成長・物価高） (`stagflation`)
* **為替レート初期値**: 165 円/ドル （悪い円安と人件費・金利高の併発）
* **シミュレーションへの影響**: 円安ストレスによる生活実感インフレの高騰と、人件費・金利高による供給収縮が同時に発生する最悪のシナリオです。企業は限界費用の高騰で供給 $Ys$ を縮小し、日銀はインフレ防衛のために利上げを強行するため、家計は「物価高」と「ローン金利負担増」のダブルパンチを受け、総需要 $Yd$ が急速に減退して失業が増加する、経済停滞のスパイラルを描きます。
## 📈 リスキリング支援パラメータ `G_reskill` の詳細

### パラメータ概要
- **変数名**: `G_reskill`
- **単位**: 兆円（政府が投入するリスキリング支援予算規模）
- **UI**: スライダー `#slider-reskill`、現在値表示 `#val-reskill`
- **デフォルト**: `0`（支援なし）

### 効果の実装
| 期間 | 生産性ブースト (`productivity_boost`) | 失業率インパクト (`reskill_unemp_impact`) |
|------|---------------------------------------|-------------------------------------------|
| **短期 (0〜8期)** | `-0.0005 × G_reskill`<br>※投資期の摩擦コストで生産性が一時的に低下 | `+0.05 × G_reskill`<br>※職業転換コストで失業が増加 |
| **長期 (9期以降)** | `+0.001 × G_reskill`<br>※スキルが実務に定着し生産性向上 | `-0.08 × G_reskill`<br>※構造的失業が解消 |

### 主要指標への波及効果

| 主要指標 | 期待される方向 | メカニズム |
|----------|----------------|------------|
| **潜在GDP (`Y_potential`)** | ↑ (長期) | 生産性向上で潜在供給が拡大 |
| **名目賃金指数 (`W_nominal`)** | 初期は横ばい/やや低下 → 長期は上昇 | `g_w` に `productivity_boost` が反映 |
| **実質賃金指数 (`W_real`)** | 同上 | 名目賃金とデフレーターの比率 |
| **失業率 (`Unemployment_Rate`)** | 短期 ↑ → 長期 ↓ | `reskill_unemp_impact` が直接加算 |
| **インフレ率 (`pi_clamped`)** | 間接的に上昇/抑制 | 賃金上昇→需要拡大→インフレ圧力 |
| **可処分所得 (`YD_real`)** | 長期 ↑ | 賃金上昇＋失業率低下で実質所得増 |
| **住宅ローン負担 (`Cost_loan`)** | 変化は小さい | 主に金利政策に依存 |

### 使い方ガイド

1. **スライダー操作**
   - UI の「リスキリング・労働流動化支援度」スライダーを動かすと `config.G_reskill` が更新されます。
   - 値は `0`〜`5`（兆円）で設定可能です。

2. **シナリオ共有**
   - 右上の「URL共有」ボタンで生成されるリンクに `reskill=` パラメータが自動付加されます。例: `...&reskill=3.0`

3. **結果の解釈**
   - **短期**: スライダーを上げるとシミュレーション開始直後に失業率が上がり、インフレがやや抑制されることがあります。
   - **長期**: 8 期目を過ぎると失業率が低下し、潜在GDP と賃金が上昇するため、可処分所得の伸びが顕著に現れます。

4. **注意点**
   - 本モデルは **摩擦コスト** と **スキル定着効果** を単純化したパラメータです。実際の政策評価では、投資規模・実装スピード・労働市場構造の詳細を別途検討してください。
