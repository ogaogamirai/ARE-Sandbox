# ARE-Sandbox

マクロ経済シミュレーションモデルなどの複雑系シミュレータを一元管理する Sandbox リポジトリ。

## プロジェクト一覧

- **[japan-economy-model/](./japan-economy-model/)**: 日本経済モデル (JAPAN-A_Core)
  - 日本銀行による国債買い入れオペ・量的引き締め（QT）統合マクロ経済シミュレータ。
  - 初期状態設定（t=0）、為替動学、利払い費の借り換え平滑化ダイナミクス、および前提条件のURLパラメータ同期・CSVエクスポート機能を統合。

## 起動方法

リポジトリルートでローカルサーバーを起動し、各プロジェクトの `ui/` ディレクトリにアクセスします：

```bash
# ローカルサーバー起動例
npx serve -l 3000
```

ブラウザで `http://localhost:3000/japan-economy-model/ui/` にアクセスします。
