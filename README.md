# 🌌 ARE-Sandbox マクロ経済シミュレーター公式解説書

本プラットフォームは、ネット上のコミュニケーションにおいて、一方的な感情論の言い合いを調停し、客観的な「前提（事実・数理的理論背景）」を共有した有意義な政策対話を行うために創出されたマクロ経済動学実験室（サンドボックス）です。

## 🕹️ 1. シミュレーターの使い方（議論の作法）
1. **初期シナリオ設定 (t=0)**: 画面上部の入力フォームから、開始時点の「名目GDP」「政府債務残高」「初期為替」「初期インフレ率」等の実態データを自由に変更可能です（前提ファクトの自由化）。
2. **政策介入（ツマミの操作）**: 「政府支出」「政策金利」「日銀国債買い入れ額」などの政策レバー（スライダー）を動かした瞬間、120期（四半期換算：30年間分）の未来 of 軌道がCanvas上にカラー線で即座に再計算・描画されます。
3. **前提の完全同期共有 (Share機能)**: 画面内の「共有リンクをコピー」ボタンを押すと、現在のすべてのスライダーと初期入力値が埋め込まれた固有のURLパラメータが生成されます。これを掲示板やチャットに貼り付けるだけで、相手のブラウザ上でも全く同じ未来の軌道を再現でき、建設的なディベートを可能にします。

## 📊 2. 主要指標および単位の定義
- **名目GDP ($Y$)** `[単位: 兆円]`: 総需要の合計。
- **政府債務残高 ($B$)** `[単位: 兆円]`: 累積する国債残高。市場金利に連動した利払い費が蓄積します。
- **インフレ率 ($\pi$)** `[単位: % (年率同期済)]`: 需給ギャップ（潜在GDPとの差）から算出される物価上昇率。
- **政策金利 ($r$)** `[単位: %]`: 中央銀行が誘導する短期金利。
- **日銀国債買い入れ額 ($Op$)** `[単位: 兆円/月]`: 月間の長期国債オペフロー（量の緩和/引き締め）。
- **日銀国債保有残高 ($BOJ$)** `[単位: 兆円]`: 日銀のバランスシートの規模（ストック）。
- **為替レート ($E$)** `[単位: 円/ドル]`: 通貨の相対価値。内外金利差とインフレ差から動的に算出されます。

## 🧠 3. 実装された経済理論的背景
本ツールは、ただのグラフィックではなく、以下の強固なマクロ経済因果律を媒介として連携しています。
- **ストック・フロー一貫性（SFC理論）**: 「誰かの支出は誰かの収入」であり、フローの累積が1円の狂いもなく国債残高や民間資産ストックの増減に変換される会計的一貫性。
- **特定期間選好・市場分断仮説**: 日銀が国債買い入れ額を減額（QT）すると、市場流通国債の需給が緩み、上乗せ金利である「ターム・プレミアム」が拡大して市場長期金利が上昇するメカニズム。
- **国債借り換え遷移（ヤコビアン平滑化）**: 日本の国債平均残存期間（約7〜9年）に適合し、金利が上昇してもその期に満期を迎えて借り換える分（全体の約3%）にのみ新金利が順次適用されるリアルな財政利払い動学。
- **金利平価（UIP）と購買力平価（PPP）の調停**: 短期的な金利差（利上げによる円高圧力）と、長期的な物価上昇差（円安圧力）がシーソーのように為替を決定するオープン・マクロ動学。

## 🚫 4. 本シミュレーターの限界
- **確率的ショックの排除**: 確率的なランダムショック（予測不能な震災や国際紛争などの外部スパイク）は数式から排除されています。
- **期待形成の不変性**: 心理的な予期（センチメントの暴走やパニック）は、一定の感応度定数として近似されており、非連続な市場の決壊は表現しきれない制約があります。
- 今後は、雇用、エネルギー、地政学リスク等の多次元変数を「ARE Sandbox」配下の個別モジュールとして順次シリーズ解放し、この限界を多面的に補完していきます。
